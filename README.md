# Expense Management System

Full-stack expense management system built using React, Node.js, Express.js, and PostgreSQL.

This project is developed using a Learning by Doing approach. Each development phase focuses on requirement analysis, implementation, debugging, testing, documentation, and review.

## Tech Stack

- React
- Node.js
- Express.js
- PostgreSQL
- Git
- GitHub
- Docker
